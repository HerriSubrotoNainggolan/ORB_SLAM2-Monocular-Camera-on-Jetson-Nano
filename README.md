## ORB_SLAM2 CUDA on Jetson Nano

Implementation of ORB_SLAM2 with CUDA acceleration on NVIDIA Jetson Nano for real-time visual SLAM applications.
## Flashing Jetson Nano SD Card

Before installation, flash the Jetson Nano image to the microSD card using [Balena Etcher](https://youtu.be/cf30ZQWauI8?si=9ssZL3k4-vuju7Tu).
Get tutorial and download [jetpack](https://developer.nvidia.com/embedded/learn/get-started-jetson-nano-devkit#intro)
